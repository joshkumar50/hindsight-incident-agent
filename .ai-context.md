# KubePilot AI Context & Codebase Map

**DO NOT EXPLORE THE DIRECTORY TREE RANDOMLY. READ THIS FILE INSTEAD TO SAVE TOKENS.**

## Architecture Overview
KubePilot is an Autonomous Kubernetes SRE Platform.
*   **Frontend**: React + Vite (Single Page Application). Located in `/frontend`.
*   **Backend**: Python FastAPI. Located in `/backend`.
*   **Agent Logic**: ReAct agent loop for interacting with Kubernetes telemetry, using LLMs.

## Directory Structure

### `/backend` (FastAPI + AI Engine)
*   `main.py`: The entry point for the FastAPI server. Contains the `POST /query` endpoint which triggers the ReAct loop.
*   `requirements.txt`: Python dependencies (includes `fastapi`, `langchain`, `hindsight-client`).
*   **`/backend/agent`**: The core AI logic.
    *   `agent_workflow.py`: The actual ReAct loop. Contains `execute_action()` and the prompt definitions for the SRE agent.
    *   `llm_client.py`: Multi-LLM router (Bedrock, OpenAI, Anthropic).
*   **`/backend/config`**: Configuration definitions.
    *   `config.yaml`: The primary config file containing LLM models and keys.
*   **`/backend/shared`**: Cross-cutting utilities.
    *   `config.py`: Pydantic models for parsing `config.yaml`.
    *   `database.py`: Contains the **Vectorize Hindsight Persistent Memory** integration for Semantic Caching.
    *   `models.py`: Pydantic data models for API requests/responses.
*   **`/backend/lambda_`**: Contains mock data collectors and legacy Lambda handler stubs.
    *   `collectors/`: Mocked `prometheus_collector.py`, `jaeger_collector.py`, `elasticsearch_collector.py`.
    *   `integrations/remediation.py`: Sends JSON payload to a webhook for auto-remediation.
    *   `ai/rca_analyzer.py`: Alternate RCA analysis module.

### `/frontend` (React + Vite)
*   `src/App.jsx`: The main UI dashboard containing the chat interface and results display.
*   `src/services/api.js`: Axios client for calling `http://localhost:8000/query`.
*   `src/index.css`: Stylesheet.

### `/infrastructure`
*   Contains Kubernetes deployment YAMLs and Docker configurations.

## State of the Project (Important Context)
1. **Live Data**: The collectors in `/backend/lambda_/collectors/` return static MOCK data for the hackathon demo. It does NOT connect to a live cluster.
2. **Auto-Remediation**: The agent currently diagnoses and recommends a fix. The `remediation.py` sends a webhook payload, but it does NOT execute `kubectl` commands automatically.
3. **Memory**: The system uses Vectorize Hindsight (`backend/shared/database.py`) to recall previous SRE resolutions instantly instead of querying the LLM again.
4. **Obsolete References**: Ignore references to `MySQL` in documentation; the app uses Hindsight for persistence.
